# purgerow

Purge timestamps and row durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/purgerow/

## Install / run

```bash
git clone https://github.com/theworker02/purgerow.git
cd purgerow
node src/cli.js
node --test
```
